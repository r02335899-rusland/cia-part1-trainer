# Ежедневное напоминание CIA Part 1 (FR-30–32)

Расписание: каждый день в 18:35, часовой пояс Asia/Oral (UTC+5). Cron: `35 18 * * *`.

## Текст задачи

Ты напоминаешь пользователю о подготовке к экзамену CIA Part 1. Ничего не изменяй в приложении и его базе — только читай.

1. Прочитай документ `progress/main` из базы артефакта https://claude.ai/artifact/9hPzfCQtBcGSprHJF1MXWn.
   Если доступа нет — пропусти строку статуса и переходи к шагу 3.
2. Строка статуса:
   - решено сегодня: `days[<сегодня, ГГГГ-ММ-ДД>]` из `goal`;
   - серия дней подряд с хотя бы одним ответом (по `days`);
   - дней до экзамена (по `exam`, если задан);
   - слабый раздел: точность `sec[X].ok / sec[X].n` < 80% при `n` ≥ 5 (самый низкий).
3. «Вопрос дня» по слабому разделу (если его нет — по разделу A):
   - ситуационный вопрос в стиле экзамена IIA, сначала на английском со словами-подсказками (MOST, BEST, FIRST, NOT, primary responsibility, must/should), затем русский перевод;
   - 4 варианта, один верный;
   - ответ и пояснение по-русски со ссылкой на стандарт GIAS 2024; номера стандартов не выдумывать.
4. В конце — ссылка на тренажёр: https://claude.ai/artifact/9hPzfCQtBcGSprHJF1MXWn
5. Отправь всё одним push-уведомлением, коротко: статус в одну строку, вопрос, ответ спрятан ниже.

Разделы: A — Основы ВА (35%), B — Этика и профессионализм (20%), C — Управление, риски и контроль (30%), D — Риски мошенничества (15%).
