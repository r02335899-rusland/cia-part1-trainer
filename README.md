# CIA Part 1 — тренажёр

Веб-приложение для подготовки к экзамену CIA Part 1 «Internal Audit Fundamentals» (программа 2025, GIAS 2024).
Требования — в [docs/PRD.md](docs/PRD.md).

- Опубликованная версия: https://claude.ai/artifact/9hPzfCQtBcGSprHJF1MXWn
- Исходник: [app/index.html](app/index.html) — одна HTML-страница без сборки

## Структура

```
app/index.html        приложение: вёрстка, стили, банк вопросов, логика
reminder/prompt.md    текст запланированной задачи-напоминания (FR-30–32)
docs/PRD.md           требования к продукту
serve.ps1             локальный сервер (PowerShell, без Node/Python)
.claude/launch.json   конфиг предпросмотра в Claude
```

## Устройство `app/index.html`

| Блок в `<script>` | Что делает | FR |
|---|---|---|
| `SEC`, `SEED`, `EN` | Разделы с весами, 27 исходных вопросов (RU) и их английские версии со словами-подсказками | 5 |
| `head()`, `streak()` | Кольцо цели, серия, темп, отсчёт до экзамена, плашка-напоминание | 1–5 |
| `pick()`, `nextQ()`, `drawQ()` | Тренировка: реже показанные первыми, перемешивание, таймер, разбор | 6–9 |
| `deep()` | «Разобрать подробнее с Claude» | 10 |
| `stem()`, `opt()`, `mark()` | Режимы языка и подсветка подсказок | 11–12 |
| `generate()` | Генерация 5 вопросов, проверка ответа модели, банк ≤ 220 | 14–17 |
| `examSetup()` … `examFinish()` | Экзамен на время, пропорции разделов, досоставление, разбор | 18–22 |
| `record()`, `wrongDraw()` | Список ошибок и повтор | 23–24 |
| `progDraw()` | Точность по разделам, слабый раздел, календарь | 25–27 |
| настройки, `save()`, `push()` | Настройки, JSON, сброс; localStorage + облачная база `progress/main` | 28–29 |

Формат вопроса: `{id, s, q, o[4], c, e, w[4], r, qe, oe[4], k[], h}` — см. PRD, раздел 5.

## Локальный запуск

```bash
powershell -ExecutionPolicy Bypass -File serve.ps1
```

Локально работает всё, кроме генерации вопросов и облачного сохранения: они требуют открытия на claude.ai
(возможности `sample` и `db` артефакта). Прогресс тогда хранится только в браузере.

## Публикация

Страница публикуется как артефакт claude.ai по тому же URL. Возможности при публикации:
`db` (правило: `progress` — чтение и запись только владельцу), `sample`, `user`.
Перед публикацией правок попросите Claude прочитать живую версию артефакта: в ней мог измениться код
с момента копирования в проект.
